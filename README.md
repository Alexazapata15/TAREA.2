# Tarea 2 - Diseño de una base de datos con estándares y buenas prácticas

**Actividad:** Tarea 2 - Diseño de una base de datos con estándares y buenas prácticas  

## Descripción

Este proyecto presenta el diseño lógico de una base de datos para una plataforma de comunidad educativa.

A partir del modelo conceptual desarrollado previamente, se realizó su transformación al modelo lógico, definiendo las tablas, claves primarias, claves foráneas y relaciones entre las entidades.

También se aplicaron las reglas de normalización correspondientes a la Primera, Segunda y Tercera Forma Normal (1FN, 2FN y 3FN), con el propósito de obtener una estructura organizada y evitar redundancias e inconsistencias en los datos.

El proyecto incluye el diccionario de datos, la explicación de las relaciones, el modelo lógico y las conclusiones del diseño realizado.
